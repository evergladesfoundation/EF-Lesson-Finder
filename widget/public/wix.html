Add the Lesson Finder chatbot to Wix

evergladesliteracy.org is a Wix site. Paste one script into Wix Custom Code to float the chat launcher on every page.

Preferred path: Settings → Custom Code (premium plan with a connected domain). Do not use the editor’s Embed HTML box for the floating launcher — Wix sandboxes that code in an iframe and the bubble cannot sit on the page. Use the iframe URL below only if you want the chat panel inside a page section.

1. Custom Code (floating launcher)

  1. Open the Wix dashboard for evergladesliteracy.org.
  2. Go to Settings → Custom Code → + Add Custom Code.
  3. Name it Everglades Lesson Finder.
  4. Paste the snippet below.
  5. Add to pages: All pages, load code once. Place code in: Body – end.
  6. Click Apply, then Publish. The widget only runs on the live site, not in the editor.

2. Embed a Site (inline panel, optional)

If Custom Code is unavailable, add Embed Code → Embed a Site and paste this URL. Size the box at least 380×520. Right-click the embed → Show on All Pages if you want it site-wide.

3. Custom Element (optional)

In Wix Studio / Editor: Add → Embed → Custom Element. Tag name everglades-lesson-finder, source URL . The panel fills the element’s box. Preview: custom element demo.
