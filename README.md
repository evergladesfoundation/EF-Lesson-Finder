# Everglades Literacy Program

An Astro + Tailwind CSS recreation of [evergladesliteracy.org](https://www.evergladesliteracy.org/), built from the public content and imagery on the live Wix site in August 2026.

## Development

```powershell
npm install
npm run dev
```

The development server runs at `http://localhost:4321`.

## Production build

```powershell
npm run build
npm run preview
```

## Routes

- `/` — Program overview
- `/about` — Mission, education program and team
- `/teacher-toolkit` — PreK–12 curriculum
- `/instructional-resources` — Supplemental lessons
- `/champions` — Champion Schools overview
- `/k-5-champions` — PreK–5 Champion Schools
- `/6-12-champions` — Champions in Action
- `/getinvolved` — Trainings and programs
- `/families-foreverglades` — Family night series
- `/teacher-symposium-2026` — Annual symposium
- `/faq` — Frequently asked questions

This educational clone is not the official website. Donation links direct visitors to the live organization site.
